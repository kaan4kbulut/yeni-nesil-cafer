## Hangisini indireyim?

| İşletim sistemi | Dosya | Kurulum |
|---|---|---|
| Linux | `{linux}` | İndir → `chmod +x {linux}` → çift tıkla ya da `./{linux}`. Menüye/masaüstüne eklemek için: `./{linux} --install` |
| Windows 10/11 | `{windows}` | İndir → çift tıkla ("Windows bilgisayarınızı korudu" çıkarsa **Ek bilgi → Yine de çalıştır**) |
| macOS 12+ | `{macos}` | İndir → aç → uygulamayı Applications'a sürükle (ilk açılışta sağ tık → Aç) |

Program ilk açılışta sistemini tarar, Ollama'yı ve sana uygun yapay zekâ modellerini kurulum sihirbazından indirir;
senden komut yazmanı istemez. `.sha256` dosyaları indirdiğin dosyanın doğrulama özetidir (isteğe bağlı).

> **Bunları indirmeyin:** `{guncelleme}` (+ `.sha256`) uygulama içi güncelleyicinin okuduğu kod paketidir; program bunu kendisi alır.
